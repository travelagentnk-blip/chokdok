# Заметки по отелям

Рабочая база отелей: что услышали → проверили → описали.

## Как устроено

```
notes/hotels/
├── README.md        — эти правила и шаблон
├── _inbox.md        — «услышала»: отели на проверку
├── turkey.md        — Турция
├── tanzania.md      — Танзания (Занзибар и сафари)
└── <страна>.md      — новая страна = новый файл
```

Внутри файла страны всегда одна и та же иерархия:

```
# Страна
## Курорт / регион
### Уровень отеля
#### Название отеля
```

Курорты внутри страны — по алфавиту. Уровни внутри курорта — всегда в этом порядке (пустые уровни не пишем):

| Уровень | Что сюда относим |
|---|---|
| **Люкс / 5\* Deluxe** | верхний сегмент, топовые сети, виллы с сервисом |
| **5\*** | классические пятёрки |
| **4\*** | хорошие четвёрки |
| **3\* и бюджет** | тройки, гестхаусы, апарты |
| **Бутик / особый формат** | небольшие дизайнерские отели, лоджи, кемпы — где звёзды мало что говорят |

Уровень ставим по нашей оценке, а не только по официальной звёздности: если «пятёрка» по факту тянет на 4\*, кладём в 4\* и пишем почему.

## Процесс

1. Услышала про отель → одна строка в `_inbox.md` (название, страна/курорт, откуда узнала).
2. Проверяем: сайт отеля, свежие отзывы, расположение, пляж/номера, цены.
3. Переносим в файл страны по шаблону ниже, из `_inbox.md` строку удаляем.
4. Если отель не подходит — всё равно заносим, со статусом ❌ и причиной, чтобы не проверять повторно.

## Статусы

- ✅ **рекомендую** — проверено, можно предлагать
- 🟡 **с оговорками** — подходит не всем, оговорки описаны
- ❌ **не предлагаем** — причина указана
- 👁 **видела лично** — добавляется к статусу, если была в отеле сама

## Шаблон отеля

```markdown
#### Название отеля
**Статус:** ✅ рекомендую · 👁 видела лично
**Проверено:** 2026-10 · **Источник:** откуда узнали
**Сайт:** https://…

- **Расположение:** район, до пляжа/центра/аэропорта
- **Пляж / территория:** …
- **Номера:** какие категории брать, каких избегать
- **Питание:** система, качество
- **Для кого:** пары / семьи с детьми / молодёжь / без детей
- **Плюсы:** …
- **Минусы:** …
- **Цены:** ориентир за ночь/тур, сезон
- **Заметки:** всё остальное (реновация, смена управления, лайфхаки)
```
